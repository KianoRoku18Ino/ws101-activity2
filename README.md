# WS101 Activity 2 — JavaScript Fundamentals & Simple Calculator

Four small vanilla JavaScript programs built for **Web Systems and Technologies 1 (WS101)**,
Quezon City University. No frameworks, no build tools — plain HTML, CSS, and JS.

## Live Demo

https://kianoroku18ino.github.io/ws101-activity2/

## What's inside

| Task | What it does |
| --- | --- |
| 1a — Three-Number Ops | Sum, product, quotient, and remainder of three input numbers (quotient/remainder chained left to right, since those two only have a standard two-number meaning) |
| 1b — Odd or Even | Checks whether an input integer is odd or even |
| 1c — Grade Equivalent | Looks up the numerical grade, descriptive rating, and remarks for a percentage score, against the table in the activity brief |
| 2 — Simple Calculator | Add, subtract, multiply, or divide two numbers, with a Reset button |

## File Structure

Two matching pairs — same content, different filenames, same reason as the portfolio repo:
GitHub Pages needs `index.html` to auto-serve, while the assignment's naming convention
needs the student-ID-based filename.

```
260003GalaridoActivity2.html   — the page (assignment naming convention)
260003GalaridoActivity2.css    — its stylesheet
260003GalaridoActivity2.js     — its script
index.html                     — identical copy, for GitHub Pages
style.css                      — identical copy, for GitHub Pages
script.js                      — identical copy, for GitHub Pages
assets/images/                 — QCU and CCS seals used in the letterhead
```

## Tech

Plain HTML5 + CSS3 + vanilla JS (no libraries). Google Fonts (Inter, JetBrains Mono).
Letterhead uses QCU's navy/gold palette; the calculator card keeps the light theme and
green actions shown in the activity brief's own mockup. No JavaScript framework, no
build step — open either HTML file directly in a browser to run it.
