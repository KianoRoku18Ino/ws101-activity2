Grade Equivalent Lookup

Goal: match a percentage score against the table above and return its grade, rating, and remarks.

The reference table's "Passing level: INC — Incomplete — Conditional" row covers a missing score rather than a percentage band, so it isn't reachable from this lookup — it's still shown above because the table is transcribed as provided.

Show the code & how it works

The table above lives in code as an array, ordered highest score-band first. Array.find() walks it top to bottom and stops at the first row the score still qualifies for — since the array is sorted, that's always the correct band. 

const GRADE_TABLE = [
  { min: 96.50, grade: 1.00, rating: "Excellent", remarks: "Passed" },
  { min: 92.50, grade: 1.25, rating: "Very Good", remarks: "Passed" },
  // ...the rest of the table, same order as above...
  { min: -Infinity, grade: 5.00, rating: "Poor", remarks: "Failed" },
];

function getGradeEquivalent(score) {
  return GRADE_TABLE.find((row) => score >= row.min);
}
