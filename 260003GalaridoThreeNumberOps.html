Three-Number Operations

Goal: practice sum, product, quotient, and remainder across three inputs instead of the usual two.

Quotient and remainder only have a standard meaning for two numbers, so this chains left to right: quotient = (a ÷ b) ÷ c, remainder = (a % b) % c.

Show the code & how it works

Reads the three numbers, then runs each operator across all three in turn. Sum and product are unambiguous (a+b+c, a×b×c); quotient and remainder are chained left to right, matching the note above. 

function computeThreeNumberOps(a, b, c) {
  const sum = a + b + c;
  const product = a * b * c;
  const quotient = a / b / c;    // (a / b) / c
  const remainder = (a % b) % c; // (a % b) % c
  return { sum, product, quotient, remainder };
}
