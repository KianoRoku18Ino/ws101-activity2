Odd or Even Checker

Goal: classify a whole number using the modulo (remainder) operator.

Show the code & how it works

Dividing any even number by 2 leaves no remainder; any odd number leaves a remainder of 1 (or −1). Checking that remainder is the entire test. 

function isEvenNumber(n) {
  return n % 2 === 0;
}
