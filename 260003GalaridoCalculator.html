Simple Calculator

Goal: a basic four-function calculator driven by an operator dropdown and click events.

Show the code & how it works

The dropdown's value is the operator symbol itself, so a single switch statement picks the matching branch — no if/else chain needed. Division checks for zero first, since that's the one case with no numeric answer. 

function calculate(first, second, operator) {
  switch (operator) {
    case "+": return first + second;
    case "-": return first - second;
    case "*": return first * second;
    case "/":
      if (second === 0) return "Undefined (division by zero)";
      return first / second;
  }
}
